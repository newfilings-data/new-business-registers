# New business registers

Monthly open data of newly registered companies, one folder per portal. Each folder has the latest month as `companies.csv` and `README.md`, and every month in `YYYY-MM/`.

Natural persons and sole traders are left out. Street addresses, telephone and fax numbers, email addresses, officer names and insurance policy numbers are not included. Source, licence and attribution are in each portal README.
